Build Spec Companion — Visual Reference · Material 3 Expressive

Sender-Centric Email Client

Static visual mockups for every core screen in the build specification, restyled on Material 3 Expressive: tonal surface containers instead of drop shadows, the M3 shape scale with large outer radii, emphasized type, filled FABs, connected button groups, a floating toolbar, and a navigation bar with pill indicators. Android frames use Roboto Flex (falling back to Roboto or the system font when offline); the Windows frame uses Segoe UI Variable. Icons are inline SVG stand-ins for Material Symbols Rounded, so the file renders fully with no network access.
